# Security Policy

## Supported Versions

This project follows an N-0/N-1 dependency freshness policy and continuous vulnerability scanning.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a Vulnerability

If you identify a security issue:

1. Do not open a public issue with exploit details.
2. Report privately via GitHub Security Advisories for this repository.
3. Include affected versions, impact, and reproduction details where possible.

The maintainers will triage reports and prioritize remediation based on severity and exploitability.

## Remediation Targets

- Critical: patch or mitigation target within 24 hours
- High: patch or mitigation target within 72 hours
- Medium: patch target within 14 days
- Low: patch target within 30 days
