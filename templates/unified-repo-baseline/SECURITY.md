# Security Policy

## Supported Versions

This repository follows:

- Continuous dependency and vulnerability scanning
- N-0 / N-1 dependency freshness policy where applicable

## Reporting a Vulnerability

1. Do not open a public issue with exploit details.
2. Report privately through GitHub Security Advisories for this repository.
3. Include impact, affected versions, and reproduction details.

## Remediation Targets

- Critical: patch or mitigation target within 24 hours
- High: patch or mitigation target within 72 hours
- Medium: patch target within 14 days
- Low: patch target within 30 days
